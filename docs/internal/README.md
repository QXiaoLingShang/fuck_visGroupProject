# 内部协作说明（docs/internal/）

这里是项目推进过程中给各成员/执行者看的内部工作说明，不是交作业的内容：

- `AGENT_BRIEF.md`：第一轮（数据下载 → 数据理解 → 数据过滤 → 数据处理 最初版本）的分工与写作规范
- `AGENT_BRIEF_R2.md`：第二轮（补充分析假设与赛题五个问题）的规范
- `AGENT_BRIEF_R3.md`：第三轮（全文精简、图表简化）的修订要求

公开仓库中这些文件已做脱敏：

- 删除了本机绝对路径（解释器目录、项目所在目录），改为“在项目根目录下运行”这类可移植描述；
- 不含成员姓名、学号等个人信息（署名信息统一由根目录 `.env` 提供，见 `.env.example`）。

文档的公共写作与图表规范以 `src/common.py` 的界面约定和本文档目录下的各 BRIEF 为准；
其中若有冲突，`AGENT_BRIEF_R3.md` 的优先级最高。
