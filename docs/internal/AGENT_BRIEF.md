# 子任务通用说明（每个子 agent 必读）

## 背景
课程小组项目（5 人），选题 ChinaVis 2024 赛道1-Ⅱ「职数洞见」多变量招聘数据可视分析挑战赛。
第一阶段作业：按“可视化七步设计方法”完成前四步（数据下载、数据理解、数据过滤、数据处理）的第一轮设计，
提交一份图文并茂的 Word 文档，每个小节标题标注主要完成人。你负责其中一位成员的小节。
最终文档由主 agent 汇总，你只产出：脚本、图片、处理结果表、一份 Markdown 小节稿。

挑战赛 5 个问题（数据处理要为它们服务）：
1. 从行业类别、薪资待遇、经验要求等多维度量化评估职位差异度
2. 挖掘职位关键特征，设计职位画像（偏好城市、薪酬待遇等）
3. 对薪酬与职位、行业、地域的关系建模，识别薪酬模式与差异
4. 地域招聘活动画像，识别招聘特征相似的地域
5. 总结行业发展动态，发现急需人才的新兴职位

## 数据
`data/raw/JobWanted.xlsx`，430,664 行 × 7 列，全为字符串，无空值，所有类别均为脱敏虚拟编码（真实含义未知）：
- job_title 职位名称（169,540 种，34 位哈希码）
- city 行政区划（371 个，如 K445；14 个城市各 2.2~2.6 万条，其余多为约 300 条）
- salary 薪酬（2,774 种写法：`5-10K`、`5-10K·13薪`、`130-180元/天`、`15-20元/时`、`5000-8000元/月`、`800-900元/周`、`5-7元/单`、`面议`、`6K以上`）
- experience 经验要求（10 种编码）
- education 学历要求（12 种编码）
- company 企业（267,296 家）
- company_type 行业类别（158 种，如 type_BLfSmG）
官方说明：数据中人为设置了缺失值、异常值、不一致等噪声（如无效薪酬、缺失行业类别）。没有时间字段、没有技能文本。

## 小节稿格式（严格遵守，主 agent 用程序解析）
- 只能使用：`## ` 二级标题、`### ` 三级标题、普通段落、`- ` 无序列表、Markdown 管道表格、图片行、代码块（```，仅在展示关键处理代码时用，每块不超过 15 行）。
- 标题不要自己编号、不要写成员名（主 agent 统一加），严格使用任务里给定的标题文字。
- 图片行独占一行：`![图题文字](output/figs/X_xxx.png)`，图题不要写“图1”这样的编号。图片前的正文要引出它，图片后要有解读（看到了什么、对后续设计意味着什么）。
- 表格前独占一行写 `表题：xxx`。表格不超过 12 行 × 7 列。
- 不要用加粗、斜体、链接、HTML、公式、一级标题。
- 全文简体中文，学术报告语气，写具体数字（来自你脚本的真实输出，不得编造）。每个二级标题下 2~4 张图、400~900 字。
- 文末不要写总结性客套话；不要提及“agent”“AI”“主 agent”。以小组成员第一人称复数（“我们”）写。

## 图表规范（必须遵守）
- 先定图表形式再定颜色。大小比较用条形图（类别多时横向、排序）；分布用直方图/箱线图/小提琴图；两类别交叉用热力图；占比用堆叠条形，不用饼图/环形图。
- 颜色：单一系列全部用 PALETTE[0]；想强调某一项用 HIGHLIGHT 其余 NEUTRAL；分类色按 PALETTE 固定顺序取、不超过 8 类（多了合并“其他”）；数值大小用单色相 `seq_cmap()`；有正负/高低于基准用 `div_cmap()`（中点为中性灰）。禁止彩虹色、禁止 jet/viridis 以外的随意 colormap（顺序色统一用 seq_cmap）。
- 禁止双 y 轴。两个量纲不同的指标用并排子图。
- 不要给每个数据点都标数值；只标关键值。条形少（≤12）时可标数值。
- 网格为实线细线（样式已全局设好），不要虚线网格；不要给柱子描边。
- 标题用中文写结论或内容（左对齐，样式已设好），坐标轴带单位（如“月薪中值（千元/月）”）。
- 编码类标签（如 type_BLfSmG）太长时可去掉 `type_` 前缀；城市直接用编码。
- 图宽 8~11 英寸，高 4~6.5 英寸为宜；多子图用 constrained_layout=True。
- 每张图保存后必须用 Read 工具打开 PNG 亲自检查：中文不乱码、标签不重叠不截断、图例不遮挡数据。有问题就改到没问题为止。
